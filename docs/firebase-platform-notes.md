# Firebase platform notes

These official Firebase contracts inform the implementation. Verify current provider requirements in the Firebase Console and Firebase documentation before enabling real school data.

- Realtime Database Security Rules are evaluated for Firebase client requests, while trusted Admin SDK calls bypass those Rules. Therefore every server route must enforce tenant membership and permission checks independently. This app denies all direct client RTDB access and routes data operations through the server. Source: [Realtime Database Security Rules](https://firebase.google.com/docs/database/security).
- Firebase Authentication supports server-side session cookies created from a client ID token through the Admin SDK. The official flow calls out CSRF prevention, optional recent-authentication checks, cookie security attributes, session verification, sign-out, and revocation behavior. E-SmartSchool.lk uses a double-submit CSRF token, verifies recent authentication and verified email, and issues an HttpOnly Secure `webdev_app_session` cookie for HTTPS Preview. Source: [Manage Session Cookies](https://firebase.google.com/docs/auth/admin/manage-cookies).
- Cloud Storage Security Rules can authorize by Firebase Auth identity and path, and validate object metadata such as content type and size. E-SmartSchool.lk applies school path/membership checks, MIME/size restrictions and deny-by-default fallback rules; trusted server upload logic still needs explicit authorization. Source: [Understand Security Rules for Cloud Storage](https://firebase.google.com/docs/storage/security).
- Firebase Admin SDK setup requires a Firebase project and service-account credentials. Firebase recommends Application Default Credentials in Google-hosted environments; when using a service-account key in another runtime, protect it as a highly sensitive server secret. E-SmartSchool.lk stores the JSON only as a protected runtime value and validates its project ID. Source: [Add the Firebase Admin SDK to your server](https://firebase.google.com/docs/admin/setup).
